## Per-match time-out override — 2026-09-26 (released)

The user clarified that an event created without an unfinished-match setup option must still be able to record 10–8 when a 24-point match runs out of time. The setup checkbox is removed; each live match instead offers an explicit "Time ran out — use score played" choice. Without that choice, the full target remains required. The confirmed result awards only actual points/games, and ties remain draws. Existing event rows are not changed. Migration `20260926110000_americano_match_time_override.sql` removes only the server-side setup-option gate, while preserving score-shape and over-target checks. This amendment was subsequently released in commit `db15a74`; the local test expectation now reflects that deployed per-match consent behavior. It is not a new database migration in the October iOS release.
