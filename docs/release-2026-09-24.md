# Web release — 24 September 2026

## Scope

- Preserve the previously released quiet KoC scoreboard and qualifier player-name fixes.
- Commit the remaining local Americano v2 / Tournament v1 development, tests and handoffs, without enabling those formats publicly.
- Show Americano and Tournament as disabled Coming soon cards; remove the legacy Americano creation fallback and prevent template-based creation while disabled.
- Production builds force both rollout gates off. Explicit development flags and the isolated `tournament-test` build remain available for engineering work.
- Do not hydrate Tournament services on the ordinary homepage while disabled; direct Tournament routes return to the library.
- Preserve existing KoC and legacy event readers. Public signups fall back to the deployed v2 reader only when the new v3 function is unavailable.

## Pro trial

- New local web-preview trials last 30 days. Existing trial endpoints and used-trial flags are not reset or extended.
- The web PWA's existing temporary free-Pro access remains unchanged.
- Native subscription entitlement/expiry remains controlled by StoreKit/RevenueCat. The paywall now displays each product's actual introductory offer instead of hardcoding seven days or falsely promising 30 days.
- The desired App Store introductory offer is one calendar month (Apple's supported equivalent of 30 days), for monthly and annual Pro. App Store Connect requires sign-in before this dashboard change can be completed; no store offer was changed during preparation.
- A web deployment does not replace the installed App Store binary. No new App Store version is submitted by this release.
